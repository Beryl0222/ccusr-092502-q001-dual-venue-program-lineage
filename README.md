# 双场域演出版本衔接

本项目保存 双场域演出版本衔接 服务的领域名词、事件信封和联调样例。当前代码只校验各业务模块共用的事件边界，便于后续服务在相同语义上演进。

## 已有资料

- `contracts/domain.json` 登记聚合类型、事件名称和基础信封。
- `data/sample.json` 提供一条可直接校验的中文联调样例。
- `src/envelope.py` 只负责共用字段与时间格式，不包含业务流程。

## 领域边界

事件标识、聚合标识、发生时间和版本用于不同模块之间的确定交接。业务事实一旦被接收就不应原地改写，更正由后续事件表达。详细业务状态、持久化、权限与对外接口由正式服务实现。

## 测试与构建

运行基础合同测试：

```bash
python3 -m unittest discover -s tests
```

执行编译检查：

```bash
python3 -m compileall -q src tests
```

两条命令均只使用 Python 标准库，可在单个 Linux 应用容器中直接执行。
